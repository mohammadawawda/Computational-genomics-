# Computational Genomics

Computational genomics projects in Python.

* [zonation_hackathon](zonation_hackathon) hackathon project. How liver cells lose their zone identity as fatty liver disease gets worse, from single cell data.
* [short_read_aligner](short_read_aligner) my own seed and extend aligner for ATAC seq reads, compared to bowtie2.
* [library_complexity](library_complexity) estimating library complexity with a truncated Poisson model.

The data files are not included.
